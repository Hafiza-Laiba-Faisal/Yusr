# Yusr — Intelligent AI Quran Coach

Yusr is a personalized AI-driven Quran tutor designed for memorization (Hifz), revision, and Tajweed improvement.

## Features
- **AI Tajweed Coach**: Real-time feedback on recitation.
- **Progress Tracking**: Monitor your memorization journey.
- **Interactive Learning**: Engage with the Quran in a modern, intuitive interface.

## Getting Started

### Prerequisites
- Node.js & npm
- Python 3.12+ (for Backend)

### Running the Application
To start both the frontend and backend:
```bash
./run_all.sh
```

### Components
- **Frontend**: Vite + React + TailwindCSS (Shadcn UI)
- **Backend**: FastAPI + Python
- **Database**: Supabase
